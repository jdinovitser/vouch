## Contest points this presentation demonstrates

- **Potential impact:** More capacity for community-serving teams and more human attention where judgment matters.
- **Technical implementation:** Strands agent path, Amazon Bedrock with honest runtime labeling, typed tools, deterministic server authorization, Postgres state, independent verification, and audit history.
- **Creativity and originality:** Verified behavior changes what the agent can actually do; authority is bounded, earned, and revocable.
- **Working proof:** Live `EXECUTE`, `APPROVAL REQUIRED`, verification failure, authority demotion, and `BLOCKED` outcomes.
- **Responsible AI:** The model recommends but cannot authorize itself, mutate protected state directly, change trust, or bypass hard safety limits.
