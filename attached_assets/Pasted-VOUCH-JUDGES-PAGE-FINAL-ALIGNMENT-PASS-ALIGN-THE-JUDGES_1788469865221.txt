4. MAKE THE TECHNICAL IMPLEMENTATION SECTION JUDGE-FRIENDLY

Use:

Technical Implementation
A real agent workflow—not a chatbot.

VOUCH uses Strands Agents + Amazon Bedrock to give the AI teammate genuine agentic capabilities.

The workflow is:

REQUEST
→ EVIDENCE
→ STRANDS AGENT
→ STRUCTURED RECOMMENDATION
→ VOUCH AUTHORITY ENGINE
→ HUMAN / AUTONOMOUS DECISION
→ ACTION
→ INDEPENDENT VERIFICATION
→ AUTHORITY UPDATE

Then explain the architecture in concise cards:

STRANDS AGENT

The agent receives a structured case, inspects evidence through tools, reasons over the available information, and produces a structured recommendation.

AUTHORITY ENGINE

A separate server-side layer determines what the agent is actually allowed to do.

HUMAN AUTHORIZATION

Higher-stakes actions can require explicit, case-bound human authorization.

INDEPENDENT VERIFICATION

Execution is not treated as proof of success. Outcomes are independently checked against durable state.

POSTGRESQL

Cases, actions, authorizations, verification results, authority, and audit information persist and affect future decisions.

Then emphasize:

The LLM is not the permission system.

and:

The agent can recommend. It cannot authorize itself.

These should be highly visible.
